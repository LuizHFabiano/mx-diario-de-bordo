# AGENTS.md

As regras para agentes de IA deste projeto estão no arquivo **`CLAUDE.md`**, na raiz do repositório.
Leia e siga o `CLAUDE.md` inteiro antes de alterar qualquer arquivo. Ele vale para qualquer ferramenta (Claude, Codex, Cursor, Copilot etc.).

Resumo do que é obrigatório: **rodar `npm run verificar` na raiz e só concluir/commitar se terminar com `APROVADO`.**
